# ระบบจัดการห้องพัก & ส่งบิลอัตโนมัติผ่าน LINE (Dormitory Management System)
> 🚀 **รันบน GitHub Pages ฟรี 100% | บันทึกข้อมูลลง Google Sheets ปลอดภัย ไม่ต้องเสียค่า Server รายเดือน**

---

## 🌟 ฟังก์ชันหลักของระบบ
1. **จัดการห้องพัก & ข้อมูลผู้เช่า**:
   - บันทึกค่าเช่า, ค่าส่วนกลาง, ค่าที่จอดรถ, ทะเบียนรถ
   - ค่าใช้จ่ายอื่นๆ พร้อมช่องระบุหมายเหตุแบบ Dynamic
   - ผูกบัญชี LINE User ID ของผู้เช่าอัตโนมัติ
2. **จดมิเตอร์น้ำ - ไฟ คำนวณบิลรอบเดือน**:
   - เลือกดูได้ทั้ง **แบบการ์ด (Card View)** และ **แบบตาราง/คอลัมน์ (Table View)**
   - ดึงเลขมิเตอร์รอบก่อนหน้ามาแสดงอัตโนมัติ
   - คิดยอดสุทธิทันที และกดปุ่มสร้างบิลได้ในคลิกเดียว
3. **ออกบิลแจ้งหนี้ & ส่ง LINE Messaging API**:
   - ส่งบิล Flex Message บัตรสวยงามเข้า LINE แชทของผู้เช่าโดยตรง
   - ส่งบิลแบบรายห้อง หรือส่งพร้อมกันทุกห้อง (Batch Send) ในปุ่มเดียว
   - ใบเสร็จ/ใบแจ้งหนี้ออนไลน์ มี QR Code พร้อมเพย์ (PromptPay) ให้สแกนจ่ายเงินได้ทันที
   - ปุ่มพิมพ์ใบแจ้งหนี้ / ใบเสร็จรับเงิน A4 พิมพ์หรือบันทึกเป็น PDF ได้ทันที

## 📋 ขั้นตอนการติดตั้งใช้งาน (ทำเพียงครั้งเดียว 5 นาที)

### ขั้นตอนที่ 1: ตั้งค่า Google Sheets (ฐานข้อมูล)
1. เปิดเว็บเบราว์เซอร์แล้วไปที่ [sheets.new](https://sheets.new) เพื่อสร้าง Google Sheets ใหม่
2. ตั้งชื่อสเปรดชีต เช่น `ระบบจัดการหอพัก`
3. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
4. ลบโค้ดเริ่มต้นทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `google-apps-script.js` ในโปรเจกต์นี้ไปวางทั้งหมด
5. คลิกที่รูปแผ่นดิสก์ (Save) เพื่อบันทึกโค้ด
6. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** สีน้ำเงินมุมขวาบน ➔ เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
7. ด้านซ้ายคลิกที่รูปเฟือง ⚙️ เลือก **เว็บแอป (Web app)**
8. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Dorm API v1`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **`ทุกคน (Anyone)`** *(สำคัญมาก ต้องเลือก Anyone)*
9. กด **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์ (Authorize access)
10. คัดลอก **URL เว็บแอป (Web App URL)** เก็บไว้ (จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

---

### ขั้นตอนที่ 2: ตั้งค่า LINE Official Account & Messaging API
1. เข้าไปที่ [manager.line.biz](https://manager.line.biz) ล็อกอินเข้า LINE Official ของหอพัก
2. ไปที่ **การตั้งค่า (Settings)** ➔ **การตั้งค่าการตอบกลับ (Response settings)**:
   - โหมดตอบกลับ (Response mode): เลือก **บอท (Bot)**
   - ข้อความตอบกลับอัตโนมัติ (Auto-response messages): **กด "ปิด (Disabled)"** *(สำคัญมาก เพื่อไม่ให้มีข้อความบอทเดิมมาตอบแทรก)*
   - Webhook: เลือก **เปิด (Enabled)**
3. เข้าไปที่ [developers.line.biz](https://developers.line.biz):
   - ไปที่ Channel Messaging API ของคุณ
   - เลื่อนลงมาที่หัวข้อ **Webhook settings**
   - นำ **Web App URL จากขั้นตอนที่ 1** ไปวางในช่อง **Webhook URL** แล้วกด Update และเปิดสวิตช์ **Use Webhook**
   - เลื่อนลงไปล่างสุดที่หัวข้อ **Channel access token** กด **Issue** แล้วคัดลอก Token มาเก็บไว้

---

### ขั้นตอนที่ 3: เปิดใช้งานบน GitHub Pages
1. ใน GitHub Repository ของคุณ ไปที่แท็บ **Settings** ➔ เมนูด้านซ้ายเลือก **Pages**
2. ตรงหัวข้อ **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** เลือก `main` และโฟลเดอร์ `/ (root)`
   - กด **Save**
3. รอประมาณ 1-2 นาที คุณจะได้ URL ประจำเว็บ เช่น `https://flookoyza-star.github.io/my-dormitory-system/`
4. เปิดลิงก์เว็บขึ้นมา ไปที่เมนู **ตั้งค่าหอพัก & ฐานข้อมูล**:
   - วาง **Google Apps Script Web App URL** ลงในช่อง
   - กดปุ่ม **"ทดสอบเชื่อมต่อ"**
   - วาง **LINE Channel Access Token**
   - กด **"บันทึกการตั้งค่า"**

## 💬 การผูก LINE User ID ของผู้เช่าอัตโนมัติ
เมื่อตั้งค่า Webhook เรียบร้อยแล้ว:
- ผู้เช่าเพียงแค่เพิ่มเพื่อน LINE Official ของหอพัก แล้วพิมพ์ **"เลขห้อง"** เช่น `101` หรือ `ห้อง 101`
- หรือพิมพ์ **ชื่อ-นามสกุล** เช่น `ชลิต พานเพ็ง`
- ระบบจะตรวจจับและดึง **LINE User ID** ไปผูกกับห้องนั้นใน Google Sheets โดยอัตโนมัติทันที!

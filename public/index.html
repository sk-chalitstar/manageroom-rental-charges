เชื่อมต่อฐานข้อมูล Google Sheets

ใช้ Google Sheets เป็นฐานข้อมูลเก็บข้อมูลห้องพัก บิล และตั้งค่าทั้งหมดแบบ Real-time

วิธีสร้าง Google Sheets & นำ Web App URL มาใส่ (ทำเพียงครั้งเดียว):

  1. เปิด Google Sheets ใหม่ที่ sheets.new
  2. คลิกเมนู ส่วนขยาย (Extensions) ➔ Apps Script
  3. ลบโค้ดเดิมทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ google-apps-script.js ไปวางทั้งหมด
  4. กด ทำให้ใช้งานได้ (Deploy) ➔ การทำให้ใช้งานได้ใหม่ (New deployment)
  5. เลือกประเภทเป็น เว็บแอป (Web app) ➔ เลือก ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone) ➔ กด Deploy
  6. คัดลอก URL เว็บแอป (Web App URL) มาวางลงในช่องด้านบนนี้

ตั้งค่าข้อมูลหอพัก & อัตราค่าน้ำ-ไฟ

ใช้สำหรับสร้าง QR Code พร้อมเพย์ให้ผู้เช่าสแกนจ่ายเงินอัตโนมัติ

ตั้งค่า LINE Messaging API (ส่งบิลอัตโนมัติ)

💡 การตั้งค่า LINE Official Account ให้ผู้เช่าแอดแล้วบอทตอบทันที:

  1. เข้าไปที่ manager.line.biz ➔ การตั้งค่า ➔ การตั้งค่าการตอบกลับ (Response settings)
  2. โหมดตอบกลับ: เลือก บอท (Bot)
  3. ข้อความตอบกลับอัตโนมัติ (Auto-response messages): ให้กด "ปิด (Disabled)" (เพื่อไม่ให้มีข้อความ 'ไม่สามารถตอบข้อความใดๆ ได้' มาขัดขวาง)
  4. ไปที่ developers.line.biz ➔ แท็บ Messaging API ➔ Webhook URL ให้ใส่ Google Apps Script Web App URL และเปิด Use Webhook
